# Progreso de Decompilación

| Dirección/Símbolo Original | Nombre Función | Estado | Notas |
|---|---|---|---|
| `0x00401000` (ejemplo) | `main` | Pendiente | Punto de entrada |
| ... | ... | ... | ... |

## Leyenda de Estados
- **Pendiente**: No analizado aún en Ghidra.
- **En Progreso**: Pseudocódigo extraído, renombrando variables y tipos.
- **Matching / Verificado**: Código C fiel al original y compila idéntico o lógicamente equivalente.
- **Ported (PSP)**: Adaptado a la capa de abstracción de PSP.
